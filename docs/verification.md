# v0.2.0 验证记录

验证日期：2026-11-09。

- 类型检查、构建与 89 项自动化测试通过。新增覆盖版本化迁移、来源原文、中文检索、两跳关联、软遗忘、反证、来源片段撤回、派生删除、旧任务拒绝写回、不同向量空间及费用换算。
- 固定合成样本含七个有答案场景：久远事件、中文近义、同名对象、否定和反证、当前与过去、普通对话观察。新召回完整证据 Recall@5 为 7/7，旧“最近 40 条”为 0/7；无答案查询候选为零。目标有意放在 60 条较新噪声之前，因此结果只证明旧截断方式的局限，不能外推为真实问答准确率；近义向量为手工模拟。
- 索引失败、取消、零写入、版本改变及重启由模拟测试验证：失败批次不自动重复，其他记忆继续处理，用户可针对原任务重试。超过 100 条排除项仍可取得后续待索引记忆。
- 模拟远程接口验证能力检查、用量缺失、错误脱敏、缓存版本、模型和维度变化、密钥隔离、取消与原单位费用记录。目标设备未配置远程向量供应商，真实供应商连接和语义质量尚未验证；本地检索可用。
- 对现有数据库的一致性副本迁移并重复打开，身份、聊天内容散列和各类原记录数量保持不变；实机加载 schema v2，自动生成迁移前备份。未重新分析全部历史聊天。
- macOS DSH 实际侧栏与记忆页已打开，原有身份、记录和形象保留，新筛选、人格档案入口与本地检索状态可见。没有向正式伙伴发送验收消息。
- 合成浏览器页面检查覆盖记忆详情、证据与反例、删除影响预览、批量操作、设置和供应商费用显示；大批量清空及 5000 条以上删除由数据库测试覆盖。
- 七项备份与回退测试覆盖已提交 WAL、文件校验、运行锁、原数据再归档、媒体和密钥保留、旧格式备份，以及中途换文件失败的自动恢复。
- 从 GitHub 开发分支全新检出、独立安装依赖后，类型检查、89 项测试及构建通过；GitHub Actions 的 Linux / Node 24 检查通过。
- 公开安装包包含代码构建产物、原创素材、文档及备份恢复工具；不包含数据库、凭据、聊天、私人截图和本机备份。

人格自然度、跨日真实成长、多窗口和系统休眠下的长期行为仍需日常使用评估。自动化模拟、界面实机检查与真实模型质量验证是不同证据，本记录不将它们等同。

# v0.1.0 验证记录

验证日期：2026-11-08。

- 类型检查、构建、46 项自动化测试通过。测试包含会话隔离、源头撤回、并发费用预留、费用不明、跨日额度、失败重试、取消、分页、安全 Markdown 渲染、CSRF、安装备份与恢复。
- 在 macOS 的 DeepSeek Harness 0.2.2-rc.1 中加载真实插件，独立侧栏入口与主面板可用；原皮肤与记账挂件保留。
- 使用隔离伙伴进行了七轮真实文字／图片对话：看图识别、流式响应、界面喂食与摸摸的动作方向、明确免打扰、无旧关系记录时承认不确定，以及基于理由赞同或不同意。
- 真实后台任务形成可追溯记忆并核算费用；自主联系评估运行后本轮选择保持安静。实际主动发消息的写入、去重和不伪造用户消息由自动化测试覆盖。
- 早期实测发现互动动作主体混淆，已明确事件中的用户动作与伙伴反馈并复测。合成浏览器测试发现浮层 pointer capture 影响点击，已修正后复测深浅色界面。
- 聊天界面采用 DSH 主题颜色、展开式回复与固定底部输入区。合成界面检查覆盖 Markdown、复制、模型设置入口、页签切换后草稿保留、390px 窄窗口及向上翻阅时流式回复不抢滚动位置。
- 验收数据与正式伙伴完全分开，旧关系记录不导入；私人数据、测试对话和备份不提交仓库。

这些结果不代表所有 DSH 版本均兼容，也不代表跨日人格成长已被证明。真实多窗口、系统休眠与长期后台运行仍需在日常使用中持续观察；测试中的模拟覆盖应与实机证据区分。
