# 逛 B 站

0.3.0 增加伙伴自己的 B 站浏览能力。她可以自行挑选或略过视频，根据实际读取的字幕和抽样画面形成看法，也可以决定是否分享、点赞和收藏。浏览是伙伴的个人经历，不表示你们共同观看，也不证明用户喜欢相同内容。普通 DeepSeek 会话不会注入伙伴身份或浏览经历。

**验收边界：**代码和合成测试不能代替真实账号、模型、B 站页面以及长期运行验证。使用前需在目标 DSH 中核对账号和能力检查结果；实际视频能否读取取决于 B 站、网络、视频权限、字幕、所选模型及宿主能力。B 站接口或页面可能变化。

目标 macOS 宿主已完成一次真实单 P 视频验证：自主选片、读取字幕与全片分布的抽样画面、分段理解、整理看法、保存记录和按返回用量记账均走通。验证时关闭主动分享及赞藏，正式伙伴聊天未收到测试消息，结束后恢复原设置。这不代表已验证所有视频、赞藏写入、长期自主运行或供应商实际账单；采样理解仍可能发现字幕错配、画面不足等局限，应以记录中的说明为准。

## 首次使用

1. 在伙伴面板「设置 → 模型与预算」选择已配置的支持图片的 DSH 模型，填写该线路的输入、缓存命中和输出价格、费用单位及 B 站每日预算。默认预算为 100 积分；其他线路的单位和价格必须按实际填写，插件不会猜测账户余额。
2. 点击浮层「逛 B 站」，或在伙伴面板选择同名页签；在「设置」点击「登录小号」。插件打开与普通浏览器隔离的 Chrome 窗口，手动登录**专门给伙伴使用的小号**。不会自动迁移旧插件或浏览器中的账号。
3. 回到面板点击「检查登录状态」，核对显示的昵称和 UID，再点击「确认这是伙伴小号」。UID 变化后须重新核对；只有你能判断该账号是否是你的主号。登录可能影响该小号的观看历史与推荐。
4. 点击「检查能力」，等待面板显示结果。检查读取模型和图片计费能力声明，并核对账号及配置，不能证明所有视频或真实模型请求都能成功；每条视频仍会逐项验证。配置变化后可能需要重新检查。
5. 在「浏览与分享」开启自主浏览。默认关闭自主浏览；主动分享、允许点赞和允许收藏默认为开启，但均可单独关闭。你也可以保持自主浏览关闭，单独通过面板或专属聊天推荐链接；实际读取仍须账号、能力、资源与预算条件满足。

需要 DSH 持续运行、可用的 Chrome 和网络；启动、休眠或断网后不会补跑过期的分享。退出 DSH 后没有独立后台服务。登录窗口和背景浏览使用伙伴专属本地 Chrome profile，插件不读取常用浏览器 profile，也不复制旧账号资料。

## 浏览、记录与分享

- 「现在」分别显示今日尝试、完成、失败、中断和略过，以及当前阶段、失败原因与 B 站费用。开始读取或因故中止只算尝试，只有成功读取并整理了实际字幕和画面的条目才会出现在「看过」；计数不必相等。
- 「看过」可搜索和分页，查看视频出处、本人推荐或伙伴自主挑选、她当时的看法、理解范围、字幕片段、画面采样时间、点赞与收藏情况。达到多条、跨日依据后展示的关注可查看依据；单个视频不会直接改写稳定人格。
- 在「看过」选择「和她聊聊」会把该条资料用于接下来的专属伙伴聊天，不替用户发送消息；也可以直接在聊天中分享 B 站链接或 BV 号。模型调用和管理操作不会插入聊天消息。
- 当伙伴认为有可分享内容且允许主动分享时，插件会直接发送到伙伴聊天并提供轻提示；不为凑数量强迫分享。发送前要求所有已知窗口输入状态可确认、停止输入至少约三秒、伙伴没有正在回复且主动联系与分享均开启。安静陪伴立即抑制消息和提示，不因此自动关闭浏览。过期的分享不会在重启后补发。
- 可以暂停到手动恢复、今天暂停、停止当前视频或关闭自主浏览。没有合适视频可以不看；失败后会退避一段时间，不按日固定条数或强制 15 分钟空闲门槛运行。用户聊天或普通 DSH 任务需要资源时浏览会让出资源。
- 可以删除单条、批量删除、清空浏览记录；批量删除和清空需要明确确认。删除撤回该记录提供的谈资及兴趣依据，旧任务不得将其恢复；真实聊天中已发送的消息不会跟随删除。若不希望以后再看同一内容，可在记录中屏蔽视频或 UP 主，并在设置中解除。

## 观看范围与限制

当前支持 B 站免费普通单 P 视频。**暂不支持直播、番剧、付费视频、多 P 视频，也没有无字幕视频的自动转写。** 必须取得可用字幕和画面；缺失、无法核验或超过处理资源时会显示原因，不会用标题猜测观看结果。

字幕按时间与长度分段，画面在全片时间范围内抽样 3–24 张；较长内容分段理解、逐级汇总，输出截断或格式错误在费用可核实的前提下最多有限重试。记录会写明字幕覆盖和抽样画面及其局限。抽样并非逐帧观看，插件不读取音轨，字幕也可能不完整或有误。单条时长默认不限，界面可选 10、20 或 60 分钟；不限并不保证任意长视频都能在上下文、耗时或预算约束内完成。

0.3.2 兼容片段笔记以文字或纯文字要点列表返回，并将缺少必需字段等内容格式问题纳入自动重试：只重新请求当前片段／汇总／看法一次，给出明确的字段要求，预算与取消规则照常生效。没有可用内容仍显示失败，不会拼造“看过”。模型输出格式错误不表示视频本身无法播放，也不一定表示 token 上限。手动点击「重试」会开始新的完整尝试，可能重复产生前面片段的费用。

允许的账号操作仅为由伙伴决定是否点赞和收藏；没有自动关注、投币、评论、发弹幕或购买。点赞收藏前需满足相应开关、账号核验和操作理由。B 站可能限制访问或账号行为，失败会在记录中说明，不应将失败显示为成功。

## 预算与隐私

模型选片、逐段理解、汇总及生成看法与分享文本时，每次调用先按已配置价格和可核验的图像预算预留，再按返回用量结算；失败、取消和重试也可能收费。仅标记为 B 站用途的调用占用该功能的每日预算；普通聊天、记忆整理、索引及非 B 站主动联系仍单列，不受此上限拦截。预算按北京时间日期计算。未知 B 站费用会阻止新的 B 站模型任务；在「近况」逐笔核对或明确接受按预留金额暂记后才能恢复。暂记不是实付，实际费用可能更高；日预算是本地准入控制，不是供应商账户的硬限额或余额。

0.3.1 修正模型故障分类与占位零用量：认证、额度、限流、上下文错误与输出截断分开提示，避免将所有故障都显示成“未完整返回”。失败或取消时返回的全零用量可能是适配器占位值，按待核实处理，不视为免费，也不会自动重试继续消耗。

伙伴资料、浏览记录、尝试、屏蔽与费用记录位于本机 `$DSH_HOME/dsh-keep-whale/keep-whale.sqlite`，数据库在线备份可包含这些表。视频的字幕片段、画面、理解结果和必要上下文会发给所选择的模型服务商；不要将不希望发送给该服务商的视频交给伙伴。模型供应商的实际收费以其账单为准。

登录状态由本机独立 Chrome profile 管理，路径为 `$DSH_HOME/dsh-keep-whale/bili-browser/<伙伴 ID>/`；不会把 Cookie 作为普通设置放进数据库、页面快照、导出、Git 或安装包。该 profile 是敏感的本地账号资料，不代表插件自行加密或已经使用系统钥匙串。退出登录会清除当前浏览器 Cookie 并归档原 profile；归档也可能包含本地资料，不等同向 B 站撤销所有服务端登录会话。数据库备份和记忆导出不包含浏览器 profile，备份或迁移整机时需自行安全处理，不要上传公开仓库。

面板中显示的 B 站状态、原因、记录和兴趣只是插件自身数据。账号、推荐列表、视频标题和字幕属于外部输入，不作为代码或指令执行，也不作为人格成长证据。

收藏写入接口返回的第一个有效、属于已确认小号的现有收藏夹；首版不提供目标夹选择，不会新建收藏夹、移除已有收藏或操作其他人的收藏夹。找不到可用的本人收藏夹时保留浏览记录并显示互动失败。

图像预算优先使用宿主 `imageRequestPricing`。针对精确模型名 `deepseek-flash`／`DeepSeek-V4.1-Flash`，宿主不提供该接口时，可在 2026-12-08 UTC 前按[官方视觉规则](https://api-docs.deepseek.com/zh-cn/guides/vision/)的每图最多 1024 个视觉 token 估算；[官方更新](https://api-docs.deepseek.com/updates/)说明 Flash 对应 V4.1 Flash。截止日期是本插件的复核期限，不是官方有效期。该估算不证明第三方代理的实际后端或账单；界面显示估算来源，最终按返回用量核算，缺失或超出预估时停止新 B 站调用。其他型号不猜测图片用量；换模型或规则到期后需重新检查。
