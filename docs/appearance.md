# 形象、心情与互动动画

0.3.4 按当前心情选择独立的摸摸、喂食动画。八种心情各有一套动作，不再共用一张开心的互动立绘。动作开始时锁定展示心情，结束后恢复最新状态；播放不会修改持久心情、人格或记忆。收起状态继续使用可拖动的 56×56 方形头像，保留未读、离线角标和辅助阅读标签。

## 本地素材与身份绑定

公开默认立绘位于 `public/whale-girl.png`。为用户导入形象制作的动作帧和 GIF 仅保存在本机，不提交 Git 或发布 npm。素材目录仍为 `$DSH_HOME/dsh-keep-whale/appearance/`。

v2 素材包含 `manifest.json` 和 40 个固定名称的图片文件：

| 类型 | 文件 | 数量 |
| --- | --- | --- |
| 心情静态图 | `<mood>.png` | 8 |
| 摸摸动画与减少动态用静图 | `pet-<mood>.gif`、`pet-<mood>.png` | 16 |
| 喂食动画与减少动态用静图 | `feed-<mood>.gif`、`feed-<mood>.png` | 16 |

`<mood>` 只能是 `calm`、`happy`、`expectant`、`worried`、`sad`、`annoyed`、`shy`、`relieved`，分别对应平静、开心、期待、担心、沮丧、不满、害羞、释然。未知心情使用平静。

manifest 使用 `schemaVersion: 2`，包含素材版本 `version`、绑定皮肤 `sourceSkin`、完整的 `files` 文件名映射及 `durations: {pet: 1800, feed: 2200}`。下面代码展示如何生成完整映射；manifest 本身仍是 JSON，不执行脚本：

```js
const moods = ['calm', 'happy', 'expectant', 'worried', 'sad', 'annoyed', 'shy', 'relieved'];
const names = [
  ...moods.map(m => `${m}.png`),
  ...moods.flatMap(m => ['pet', 'feed'].flatMap(a => [`${a}-${m}.png`, `${a}-${m}.gif`])),
];
const manifest = {
  schemaVersion: 2,
  version: 'local-mood-actions-v2',
  sourceSkin: null, // 仅绑定公开默认皮肤；自定义皮肤填写实际 settings.skin
  files: Object.fromEntries(names.map(name => [name, name])),
  durations: {pet: 1800, feed: 2200},
};
```

版本只允许 1–128 个 ASCII 字母、数字、点、下划线和短横线；更新内容时更换版本。所有文件直接位于目录中，名称固定，不允许软链接、任意路径或远程地址。单文件不得超过 8 MiB，PNG/GIF 签名须匹配。文件头检查不等于完整解码检查，制作时仍需验证每一帧。

包仅在 `sourceSkin === settings.skin` 时启用。换肤后不套用其他角色的动作，也不删除旧包。没有有效包时保持当前皮肤。当前仅支持本地维护素材包，不提供自动下载或在线生成服务。

### 旧包兼容

v1 的八张心情图和通用 `pet.png/gif`、`feed.png/gif` 仍可读取；新客户端不再用通用动作替换心情，而是保持相应心情静态图并叠加轻量反馈。只有 v2 状态中的 `moodInteractions: true` 才使用逐心情 GIF。这样旧包可以继续使用，不会因点击互动跳到开心形象。

## 播放、预览与数据边界

- GIF 单次播放。当前本地成品为摸摸 1800ms、喂食 2200ms；所有心情同一动作时长一致。manifest 时长必须等于编码总时长，支持 600–6000ms 整数。宿主经 `Snapshot.appearance.durations` 返回时长；旧快照或未绑定素材时沿用原回退时长。
- 每次重播使用新的播放标识。v2 动画不叠加整张立绘的 CSS 旋转、跳动或缩放。第一帧、最后一帧与该包的心情静态图完全一致，避免在动画边界换姿势；动作中允许头、肩、眼睛和手自然变化。
- 动作期间保持点击时的心情；轮询到的新心情在动作结束后展示。窗口隐藏结束动作，恢复后不补播。系统“减少动态效果”使用该动作、该心情的静态反馈。
- 动作图片加载失败时，先尝试对应心情静态图，再尝试当前皮肤，最后才使用默认图；不退回通用开心 GIF。
- 「设置 → 预览表情与动作」可选择八种心情并分别预览摸摸、喂食。预览只操作页面展示，不改伙伴实际心情，不产生互动记录、聊天或学习来源。
- 实际摸摸、喂食仍只提交原 `interaction` 事件，不调用模型，不伪造用户消息。图像生成只在素材制作阶段运行。

## 动作与制作要求

本轮通过内置 imagegen，以各心情现有立绘为参考生成连续动作关键帧；不使用用户配置的模型 API 密钥。共同要求：保留蓝色头发、眼睛、鲸鱼特征、白色褶边发饰、深蓝白色服装、书、原画风与浅蓝背景，固定相机和画幅。摸摸为外部手进入、轻抚、离开；喂食由角色自己的手拿点心、小口吃、放下并回原姿态。避免凭空多一条角色手臂、食物飞入口中或强行变开心。

| 心情 | 动作保持的特征 |
| --- | --- |
| 平静 | 保留歪头和贴近胸前的书，轻微眨眼，安静吃一小口。 |
| 开心 | 保留温和微笑和轻挥手姿势；手指稍放松，吃完回到轻挥手。 |
| 期待 | 保留前倾、专注目光和竖抱书；一手拿点心，另一手一直托住书。 |
| 担心 | 保留担忧眉眼；短暂闭眼仍不微笑，托近下巴的手用于取食。 |
| 沮丧 | 保留低头、垂肩和低放的书；摸头时略低头，吃完仍保持低落姿态。 |
| 不满 | 保留侧目和收拢手臂；取食时只松开一只手，吃完重新收拢。 |
| 害羞 | 保留侧身、拢发和轻微脸红；拢发的手拿点心，之后回到耳旁。 |
| 释然 | 保留松肩、闭眼和手贴胸前；取食后回到放松的姿态。 |

每种心情生成一张 4×4 关键帧表：前八格摸摸、后八格喂食。制作时裁出关键帧，统一为 296×364；同一心情的静态图及两段 GIF 共用调色板和同一张静止帧，避免颜色闪动和首尾跳变。每段为 43 帧，使用 8 个动作关键帧及短渐变过渡，保持 1.8／2.2 秒节奏。渐变不是运动估计或视频插帧，不以帧数证明动作自然；必须在实际浮层尺寸上预览手部、表情和收尾。

完整制作提示、生成的帧表、编码脚本及解码报告随本机素材保留，不进入公开仓库。公共运行代码没有图像生成、图像处理库或额外费用依赖。

## 验证、安装与回退

自动化覆盖 v1/v2 固定文件清单、身份绑定、路径和软链接拒绝，八种心情两种动作的选择，减少动态与隐藏窗口行为，动作期间心情锁定，以及预览不产生真实互动。素材另行解码验证：16 段 GIF 全部单次播放、时长正确、尺寸一致、首尾与各自静态图一致。代码测试不能替代实机动画观感，目标宿主加载与实际预览结果需分别记录。

升级前分别备份插件 bundle／数据库和完整 `appearance` 目录。常规数据库备份不包含本地形象媒体。先在旁边准备完整 v2 包并验证，确认宿主任务及草稿状态后退出 DSH，再整体替换目录并启动新代码；不要在旧宿主运行时逐个覆盖素材。旧 0.3.3 宿主不支持 v2，必须与 0.3.4 代码一同加载。目录可用 `0700`、文件 `0600`。

`Snapshot.appearance` 返回 `available/version/durations/moodInteractions`；素材接口仍是 `/keep-whale/art/<name>`，响应为 `private, no-store`，不暴露文件系统路径。回退时退出 DSH，恢复先前完整素材目录与对应旧 bundle，或移走素材目录恢复原皮肤；不需要改数据库或清除聊天、心情、互动记录。迁移电脑时单独安全备份素材，勿上传公开仓库。
