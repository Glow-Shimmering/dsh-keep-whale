# 形象、表情与互动动画

0.2.3 将视觉表现与真实心情分开：现有心情决定展示图片，互动只临时播放动作。心情图可以同时改变表情、头部角度、肩膀和手臂姿态，而不只是更换眉眼。它不会为了播放表情而修改心情、人格或记忆。收起状态显示可拖动的 56×56 方形头像；点头像展开，未读和离线状态用角标，名字和状态仍可通过悬停与辅助阅读获得。

## 本地素材与身份绑定

公开默认立绘继续位于 `public/whale-girl.png`。为用户导入形象制作的表情、动作帧和 GIF 属于本地素材，不提交 Git、不发布 npm。当前实现加载一个素材包：

```text
$DSH_HOME/dsh-keep-whale/appearance/
  manifest.json
  calm.png        happy.png       expectant.png   worried.png
  sad.png         annoyed.png     shy.png         relieved.png
  pet.png         feed.png
  pet.gif         feed.gif
```

八张静态图分别对应平静、开心、期待、担心、沮丧、不满、害羞、释然；未知心情使用平静。`pet.png` 和 `feed.png` 是降低动态时的静态反馈。示例 manifest 中媒体 ID 是合成占位符，必须替换为当前 `settings.skin` 的实际值；公开默认皮肤使用 `null`：

```json
{
  "schemaVersion": 1,
  "version": "local-whale-v1",
  "sourceSkin": "/keep-whale/media/00000000-0000-0000-0000-000000000000",
  "files": {
    "calm.png": "calm.png", "happy.png": "happy.png",
    "expectant.png": "expectant.png", "worried.png": "worried.png",
    "sad.png": "sad.png", "annoyed.png": "annoyed.png",
    "shy.png": "shy.png", "relieved.png": "relieved.png",
    "pet.png": "pet.png", "feed.png": "feed.png",
    "pet.gif": "pet.gif", "feed.gif": "feed.gif"
  },
  "durations": {"pet": 1800, "feed": 2200}
}
```

版本只能使用 1–128 个 ASCII 字母、数字、点、下划线和短横线；内容升级时改变版本，避免浏览器沿用旧图片。所有文件须直接位于目录下，文件名固定，无符号链接，单个不超过 8 MiB，PNG/GIF 文件签名需匹配。宿主不暴露文件系统路径、不执行素材、不接受任意 URL 或目录穿越。文件头校验不是完整图像解码验证，制作时还需实际解码与预览；浏览器加载失败会回退原皮肤。

素材包仅在 `sourceSkin === settings.skin` 时生效。用户换肤或恢复默认后，原包不匹配即停用，不能把原角色表情硬套到新角色上；原皮肤与包不被删除。当前仅支持本地文件维护素材包，不提供任意远程下载或自动生成服务。

## 播放与互动边界

- 互动 GIF 仅播放一次。本次本地包为摸摸 1800ms、喂食 2200ms；manifest 的 `durations` 必须与 GIF 编码总时长一致，支持 600–6000ms 的整数。宿主将有效时长放入 `Snapshot.appearance.durations`，浮层和设置预览都按它结束动作。旧包仍可使用原有 2600/3200ms，旧快照或未关联素材时回退原时长。每次重播使用不同播放标识；请求失败则取消动作并显示原有安全提示。
- 播放期间避免再叠加整张立绘旋转、跳动或缩放。结束后恢复当时的真实心情，包括担心、不满或沮丧。
- 系统“减少动态效果”使用静态反馈，窗口隐藏会结束动作，返回前台不补播。
- 没有关联包时仍显示用户当前皮肤，保留轻量反馈；不会擅自切换为默认角色。
- 实际摸摸和喂食仍仅提交原来的 `interaction` 事件，不调用模型、不伪造聊天。设置内预览只切换本地展示，不产生互动、聊天或学习来源。

## 素材制作参考

本次使用内置 `imagegen` 制作表情与动作关键帧；没有使用用户的模型 API 密钥。图像生成不是视频生成：连续关键帧在本机统一画幅、共用 GIF 调色板并编码为短动画，保留有限过渡及自然停顿。不要把单张图的整体左右摇摆称为角色动作，也不要把帧间渐变等同于运动估计或视频插帧。

生成提示的共同要求：以当前皮肤为明确编辑对象，保留脸部身份、蓝色头发和眼睛、白色褶边发饰、深蓝白色服装、鲸鱼特征、原像素画风和浅蓝背景；固定相机、整体人物比例与腰部画幅。心情变体允许头、肩、手臂与书的位置发生清楚且自然的变化，不能只换眉眼；保持两条手臂和手部结构连贯。避免夸张符号、额外人物、文字、水印或重新设计角色。

| 素材 | 表情／动作提示 |
| --- | --- |
| 平静 | 沿用原图，作为自然静止基线。 |
| 开心 | 肩膀打开、头更正，一手在肩旁轻挥，另一手把书放低；温和微笑。 |
| 期待 | 身体微前倾、抬头专注，两手分别握住竖在胸前的书边，手肘收近；不是惊吓。 |
| 担心 | 略侧身，一手托近下巴，另一手低抱书；眉心微抬、目光关切，不慌张。 |
| 沮丧 | 垂肩低头，两手把书横放低至腰前；目光向下，不夸张哭泣。 |
| 不满 | 站姿稍直、下巴微抬，双臂在书前自然收拢；平稳侧目，有保留而非愤怒。 |
| 害羞 | 身体略侧转，一手拢耳旁头发，另一手低抱书；轻微侧目和脸红。 |
| 释然 | 肩膀松开，一手轻放胸前、一手低托书；闭眼轻轻呼气。 |
| 摸摸 | 固定机位 4×3 十二格连续关键帧：原姿势 → 指尖进入 → 手靠近 → 轻触 → 向左轻抚、眼半闭 → 闭眼微低头 → 轻抚返回 → 抬手 → 手退出 → 睁眼 → 头恢复 → 原姿势。角色双手持续持书，不凭空增加手臂。 |
| 喂食 | 固定机位 4×3 十二格连续关键帧：原姿势 → 手放低 → 拿起点心 → 抬到胸前 → 送近嘴边 → 小口咬 → 放低一点 → 轻嚼 → 继续放下 → 点头收手 → 手回书上 → 原姿势。保持手腕和握持连贯，不让食物悬空飞入嘴里。 |

本地成品画幅为 296×364；两段 GIF 各 45 帧，包含 12 个关键帧和 33 个各 30ms 的短过渡，分别为 1.8 秒与 2.2 秒。摸摸关键帧停留 60–80ms，喂食 90–130ms，避免旧版长停顿；不是简单把同一张图左右摇摆，也不是视频运动插帧。实际观感须在浮层尺寸上检查：不能只看放大的关键帧就断言播放自然。素材处理工具属于制作环境，不是插件运行依赖。

## 安装、检查与回退

先保留当前 `appearance` 目录（若存在）与原皮肤，再在旁边准备完整新目录，解码检查每张图片和 GIF、核对尺寸／时长／单次播放、预览动画，然后整体替换目录；不要在生效目录里逐个覆盖半套文件。可使用目录权限 `0700`、文件 `0600`。`Snapshot.appearance` 返回 `available/version/durations`，素材接口为 `/keep-whale/art/<name>`，响应为私有 `no-store`。没有有效包时插件继续正常显示原皮肤。0.2.2 宿主只接受旧固定时长，首次使用新时长包必须同时加载 0.2.3 代码；确认宿主无进行中的任务和草稿后再重启。

回退时恢复先前的完整目录，或移走当前 `appearance` 目录以恢复原皮肤展示；不改数据库，不删除聊天、心情或互动。常规数据库/bundle 备份不包含本地媒体或表情包，二者保留在原位；若迁移整台电脑，应单独备份这些本地素材且不要上传到公开仓库。
