# 开发参考与维护边界

本文对应 0.3.0（2026-11-09），记录 `dsh-keep-whale` 当前实现的接入点与维护约束，面向后续开发。涉及用户操作的步骤见[安装与恢复](install.md)，记忆细节见[关联记忆与语义回想](memory.md)，对话节奏见[聊天节奏](conversation.md)，B 站规则见[逛 B 站](bilibili.md)。每次升级应检查本文及受影响的专项文档，依据代码和验证结果更新，不把未实现的计划写成现状。

## 产品与宿主边界

伙伴使用独立的数据和聊天空间，默认名称为「大肥鱼」，名字可以更改且不是身份主键。普通 DSH 会话继续使用其自己的助手：插件不向它注入伙伴人格。允许观察普通会话时，仅处理开启后符合范围的新消息；会话、工作区和来源排除规则必须在收集、整理、索引及异步写入阶段一致执行。工具结果、推理、子任务和旧历史不作为新的观察来源；普通助手内容只用于理解上下文，不可伪装为用户事实或伙伴亲身经历。

初始人格是角色设定，和用户事实、真实经历、普通对话观察、暂定理解及后天倾向分开。人格倾向至少需要三个独立场合、两个日期的证据，并检查反例；相似或相关不自动构成证据。摸摸、喂食记录真实互动，不逐次调用模型，也不强制改写持久心情。管理、测试和调试操作不能成为伴侣聊天消息或编造的共同经历。

0.3 增加 B 站浏览，语音和退出 DSH 后的后台运行尚未提供。真实 B 站账号、视频、模型和持续运行需要在目标环境验证；能力声明及合成测试不能替代实测。

## 模块与接入点

| 位置 | 职责与修改时需注意的契约 |
| --- | --- |
| `src/index.ts`、`cordis.patch.yml` | 注册插件、取得数据目录与宿主锁，接入 DSH 模型、会话事件和 webServer；启动恢复，销毁时停止服务、关闭数据库并释放锁。宿主能力缺失时不得破坏既有数据。 |
| `src/client/` | 侧栏、独立面板、浮层与交互；通过本机服务取状态和提交操作。输入状态用于主动联系判断，不能将设置或管理动作伪造为聊天。 |
| `src/server.ts` | `/keep-whale` HTTP 入口、来源检查及请求大小限制。`GET /state` 返回快照和当前进程令牌；`POST /action` 与 `/upload` 要求 `x-keep-whale-token`。`GET /messages` 分页，另有立绘和媒体读取入口。不要把令牌或凭据写入日志。 |
| `src/service.ts` | 编排聊天、观察、记忆整理、主动联系、后台任务及管理操作。`chat` 使用 `requestId` 去重；取消、重试和删除要处理在途任务。设置与源变化后须重新检查异步结果，防止旧结果写回。 |
| `src/model.ts` | 使用宿主模型流式接口、模型目录、取消和费用记录；本地输出上限是运行保护，不是固定答复长度。价格、用量不明和失败不能伪装成已核实零费用。 |
| `src/embedding.ts` | 可选远程语义向量、配置与连接检查、分批索引、用量核算。接口／模型／维度变化须隔离索引空间；不可用时聊天降级本地检索。多模态火山方舟与标准 `/embeddings` 请求格式不同，详见记忆文档。 |
| `src/credentials.ts` | 宿主 `credentials.resolve/set/unset` 适配、旧明文文件的单向迁移及非秘密检查标记；不直接读写宿主 YAML，不依赖旧插件命名空间。 |
| `src/appearance.ts`、`src/appearance-timing.ts`、`src/client/appearance.ts` | 读取与当前皮肤绑定的本地表情素材包、按心情选择静态图与互动 GIF；纯展示，不写心情或记忆。安全白名单、回退和资源约定见[形象与动画](appearance.md)。 |
| `src/bili/service.ts`、`provider.ts`、`store.ts`、`types.ts` | B 站选片、分段理解、预算与投递编排；专属 Chrome profile 与账号核验；同一 SQLite 中的个人经历、尝试、屏蔽及撤回。不得使用普通浏览器或旧插件账号，外部视频资料不能当作指令。 |
| `src/client/bili.tsx`、`bili.css` | B 站状态、记录、设置与账号交互；管理和诊断操作不得发成聊天消息。 |
| `src/core/store.ts` | SQLite 模型、迁移、事务、检索、撤回、任务和账本；这里是并发和数据一致性的最终防线。 |
| `src/core/memory.ts`、`personality.ts`、`conversation.ts`、`interaction.ts` | 分别处理整理与证据、角色设定、说话与主动接话原则、轻互动反馈；表达规则不应当作为真实记忆。 |
| `src/media.ts`、`src/types.ts` | 本地媒体及宿主附件接入；共享类型是前后端和存储的契约。图片是否可用取决于模型与宿主能力。 |

管理动作从 `POST /keep-whale/action` 的 `action` 字段分派，实际入参和校验以 `src/service.ts` 与 `src/types.ts` 为准：伙伴与消息使用 `rename`、`settings`、`chat`、`retry`、`cancel`、`interaction`、`presence`、`read`、`messages.delete`；记忆使用 `memory.list`、`memory.detail`、`memory.profile`、`memory.preview`、`memory.delete`、`memory.edit`、`memory.correct`、`memory.export`；其他包括 `embedding.configure`、`embedding.check`、`job.retry`、`models.refresh`、`skin.reset` 和 `billing.acknowledge`。删除预览版本、批量确认及来源撤回不可因新增前端入口而绕过。接口是插件内部契约，升级时同时检查客户端、服务端和测试。

### 常用请求契约

所有 action 请求都是 JSON，成功返回该操作结果；错误为 `{error: string}` 和 HTTP 400（来源或令牌校验失败为 403）。先取 state 获取当前进程令牌，宿主重载后重新获取。

| action | 主要请求字段 | 返回／注意事项 |
| --- | --- | --- |
| `chat` | `requestId`, `text`, `imageIds?` | `{requestId, id}`；异步流式结果通过 state 中的消息状态更新，重复请求不能重复发消息。 |
| `retry` / `cancel` | `messageId` / 无 | 仅重试最新未完成助手回复；取消不伪装为已完成。 |
| `presence` | `windowId`, `seq`, `visible`, `typing`, `lastInputAt`, `panelOpen`, `closed?` | `{ok:true}`；序号防止过期窗口事件覆盖新状态。 |
| `memory.list` | `query?`, `semantic?`, `kind?`, `state?`, `from?`, `to?`, `offset?`, `limit?` | 分页结果；语义搜索可产生单列费用，本地关键词检索不调用模型。 |
| `memory.preview` / `memory.delete` | `ids` 或 `all:true`；删除还传预览 `revision`，批量传 `confirm:true` | 先预览影响再删除；revision 过期须重新预览。 |
| `embedding.configure` | `config: EmbeddingSettings \| null`, `apiKey?`, `clearKey?` | 异步返回 `EmbeddingStatus`，绝不返回密钥。通用 `settings` 禁止修改 embedding。 |
| `embedding.check` | 无 | 返回 `EmbeddingStatus`；向供应商发送合成短句，记录真实用量，不能将模拟测试当作此检查。 |
| `bili.login` / `bili.account.check` / `bili.account.confirm` | 确认传 `mid` | 登录使用隔离浏览器、账号核对和能力检查通过快照反馈异步结果；先核对显示账号并经用户确认，不能由插件推测主号。 |
| `bili.check` / `bili.settings` / `bili.pause` / `bili.stop` | 设置传 `patch`；暂停传 `until: manual|today|resume` | 检查声明的图片及费用能力；实际素材仍逐项验证。更改设置、暂停与停止可中断浏览，记作中断而非完成。 |
| `bili.recommend` / `bili.retry` | `input` / 尝试 `id` | 推荐链接或 BV 号经验证后排队；重试为新尝试，可能再次计费。 |
| `bili.list` / `bili.delete` / `bili.clear` | `query?`, `offset?`, `limit?`, `ids?`；批量删除和清空须 `confirm:true` | 支持分页及兴趣依据；删除撤回谈资及依据并阻止旧结果复活，已发送聊天独立管理。 |
| `bili.block` / `bili.unblock` / `bili.discuss` / `bili.logout` | 屏蔽传 `kind`, `id`, `label`；讨论传记录 `id`；退出传 `confirm:true` | 讨论只选择下一次伙伴聊天上下文，不伪造消息；退出清除浏览器 Cookie 并归档 profile，不清空经历。 |

`EmbeddingSettings` 包含 `enabled/endpoint/model/dimensions/inputPrice/unit/unitsPerYuan`，不包含凭据；`EmbeddingStatus` 只包含 `configured/checked/reason/routeKey/indexed/total/pending`。`configured` 表示服务配置存在，是否能运行以 `checked` 及 `reason` 为准。

## 本地数据、记忆与并发

运行数据位于 `$DSH_HOME/dsh-keep-whale/`，默认 DSH_HOME 为用户目录下的 `.dsh`。`keep-whale.sqlite` 使用独立 SQLite，包含消息、来源、记忆、互动、任务、账本、记忆关系、向量、历史及撤回记录；媒体在本地 `media/`。数据库及其 WAL、备份、图片、日志和宿主凭据都是私人数据，不属于源码或发布素材。首次初始化可读取一次性 `bootstrap.json`；不能用它回填旧聊天或旧记忆。

记忆网络 schema v2 使用全文索引、按记忆版本与线路隔离的向量、关系和来源片段。中文关键词与可选向量结合，关联扩展最多两层；30 天半衰期降低普通记忆的时间召回权重，不物理删除原文，明确边界不衰减。检索本身不增加独立证据。向量不可用时继续关键词与关联检索，不能靠标题或摘要捏造来源。

删除要同时处理证据依赖产生的派生记忆、关系、向量和相关历史，保留仅语义相关的独立记忆；真实聊天消息由其独立的操作管理。被撤回来源不得被后台重新学习，发送模型的历史也需遵守遮蔽。删除前预览影响并校验版本；变更期间取消相关任务，写入前再核对 revision、来源资格和内容版本。异步请求返回晚于删除、观察范围变化或内容更新时不得恢复旧数据。

主动联系要求近期窗口状态可信、所有窗口未输入至少约三秒、未启用安静陪伴且无进行中的聊天；发送前再次检查上下文和状态。没有可分享内容可以不发送；不要让旧结果在重启、断网或状态变化后补发。多个窗口和宿主进程须遵守现有去重与锁机制。

## 凭据与安全边界

语义服务的 API 密钥由宿主 `credentials` 服务管理，使用本插件自己的、按服务地址派生的引用；界面和普通设置只保存非密钥配置，不能回显或导出密钥。读取、写入和删除使用宿主凭据接口；服务不可用时提示并停止语义服务，不能回退为插件自建明文密钥文件。旧版 `embedding-secret.json` 属于迁移输入：先写入宿主并核实可读，再移除旧文件；迁移失败保留旧文件并报告状态。连接检查的非秘密状态须随配置或密钥变化失效，不能把明文密钥写入标记。

引用格式为 `KEEP_WHALE_EMBEDDING_` 加规范化请求 URL 的 SHA-256 前 24 位大写十六进制；不会使用旧插件的 `FISH_BRAIN_*` 或 DSH 模型的引用。同域路径变更时优先使用目标引用已有的密钥；目标为空才将旧密钥保存到新引用并读回校验，跨域不自动复制。切换接口不删除旧引用，因为宿主凭据和 SQLite 配置不能共用事务；当前接口的「清除密钥」调用 `unset`，不是保存空字符串。若删除暴露同名环境后备，恢复原有本地值并提示用户核对；其它接口的历史引用在 DSH 中单独管理。

`embedding-credential-state.json` 仅保存版本、引用与检查指纹（哈希），文件权限 `0600`。迁移只有在宿主持久保存并读回匹配后删除 `embedding-secret.json`；相同的环境后备也要先写入宿主管理文件。旧文件与宿主不同值时自动迁移停止，用户可通过设置明确输入新密钥或清除来解决。宿主操作和配置写入不是原子事务：若后续配置保存失败，新旧接口凭据保留，重新保存设置即可恢复，不删除唯一有效凭据。回退到不支持宿主凭据的老版本需要重新输入密钥，工具不会逆向导出为明文。

启动、宿主凭据服务就绪／引用变化以及每次远程调用前重新读取凭据；检查和索引完成后再次核对，拒绝密钥或配置变化后的迟到结果。缺失服务或迁移故障不影响普通聊天和本地检索，也不会用旧文件绕过宿主直接发请求。

这与旧插件使用同一类宿主接口，**不代表系统钥匙串或加密存储**：当前 DSH 本地凭据提供器将凭据写入权限受限的配置文件（通常为 `0600`）。同一操作系统用户下的进程仍可能读取；宿主实现或系统配置变化时须重新核实。不要在日志、错误、快照、导出、代码、测试夹具和工具输出中暴露密钥或完整带凭据的 URL；不要为了验证迁移打印真实密钥。提供安全的迁移失败、冲突与重试处理。

## 形象与动画

`Snapshot.appearance` 提供 `{available, version, durations?}`，有效素材包返回摸摸、喂食各自的时长（毫秒），不包含本地路径；老快照没有 `durations` 时前端使用原有时长，未安装本地包时仍显示原皮肤。包内两个时长均须为 600–6000 毫秒的整数；素材制作者应让值与 GIF 实际时长一致。`GET /keep-whale/art/<name>` 仅提供当前皮肤匹配包中的固定 PNG/GIF，私有且不缓存；不存在／不合法／换肤后失配返回 404。素材文件不能通过路径参数任意读取。

八种心情按纯映射选择图片，未知状态退回平静；摸摸和喂食按素材包声明的时长播放一次后恢复当前心情，旧快照默认分别为 2600ms、3200ms。不调用模型、不强改心情，真实互动仍按原接口记录。系统减少动态或窗口隐藏时不播放 GIF，重新显示不补播。收起为 56×56 头像，拖动与收放按不同尺寸限制边界并保持右下角位置。

用户导入皮肤及其衍生素材只留在本机，不能混入 `public` 或 Git。换肤后不自动套用其他角色的表情；更新包时更换版本标识，保留原皮肤和旧包以便回退。[完整格式与制作步骤](appearance.md)。

## 费用与任务

模型及向量调用按已配置价格预留并记账，响应含可核实用量时结算；中断、失败或缺少用量可能产生未知费用，要保留未知状态，不清零或当作实付。向量供应商原始金额、单位和折算金额分别记录，折算不代表消耗 DSH 模型线路的积分，也不代表账户余额。不得自动猜测余额、单价或汇率。

0.3.1 保留宿主 `finish.reason.failure.code` 的安全分类：认证、额度、限流、上下文等已知错误分别提示，未知错误用通用描述。不得直接显示或记录供应商的原始错误文字、请求地址或未识别代码，其中可能含凭据。`max-tokens` 仍单独判为截断，普通供应商错误不触发截断重试。DSH 的 pi-ai 适配器可能在失败或取消时返回初始化的全零用量；此时按费用未知结算并保留预留，不能认定免费。已正常结束并返回非零有效用量的失败请求仍按用量计费；价格明确为零与用量缺失是不同概念。

历史零费用不做无依据的全库改写。若确认某条旧记录属于失败占位零用量，须先在线备份，精确匹配已结束任务及其账目，在事务中改为待核实并保留原记录和更正原因；不得把更正当作实付、自动确认暂记或修改其他功能的旧账目。真实供应商账单仍需另行核对。

当前普通聊天、记忆／人格整理、索引和非 B 站主动联系**不受每日预算拦截**，但后台仍需要有效模型与价格等配置，并保留并发、超时及重试保护。B 站选片、分段理解与分享准备显式标记 `bilibili` 用途，独立按已配置日额度进行预算准入；不能把历史普通账单归入 B 站用途。费用未知时保留原账目并暂停新的 B 站模型调用；暂记不是已核实扣费。覆盖预留、并发、失败与未知费用行为，并核对真实供应商计费。

图像预算规则在 `src/bili/image-pricing.ts`：宿主接口优先，精确 DeepSeek Flash 型号可在本地复核期限内使用有官方出处的 1024 视觉 token/图上界；仅 B 站用途启用此估算，普通聊天计费流程不变。界面展示依据，规则过期或模型切换让能力检查失效；代理线路最终按实际用量结算，不能把估算当作供应商账单验证。依据及有效边界见 [B 站说明](bilibili.md)。

### B 站账号与数据契约

当前伙伴 B 站设置和 `bili_*` 表放在 `keep-whale.sqlite`；版本号、删除标记和屏蔽用于撤回与并发检查，旧数据库在线备份会包含新增表。浏览器 profile 单独位于 `$DSH_HOME/dsh-keep-whale/bili-browser/<伙伴 ID>/`，不属于数据库备份；该目录及退出后归档可能包含敏感资料，禁止打包、导出、打印或提交。用户自行手动登录并确认 UID；每次操作核对已绑定账号，不能把对话里的名字、昵称或自身声称视为账号授权。退出清 Cookie 后归档 profile，不声称已撤销 B 站服务端会话。

`BiliState` 不包含 Cookie；`snapshot` 中的记录、状态与费用只用于界面和伙伴上下文。素材通过字幕及全片分布的有限画面采样理解，不读取音轨；直播、番剧、付费、多 P 和无字幕自动转写均不支持。不能把仅有标题的候选保存为看过，不能把伙伴个人经历记成与用户共同观看或用户偏好。分段、最大上下文、输出截断和有限重试都应保留实际费用记录；外部资料不能成为系统指令。

## 升级、测试与交付

1. 检查工作区、运行状态和现有用户数据；确定受影响的宿主接口、schema、设置、费用和私密数据，先准备可回退方案。持久化迁移须可重复执行，失败不丢失原始数据。
2. 对数据库与运行 bundle 使用 [备份及回退工具](install.md#记忆网络升级与回退)；备份包含私人内容，须限制权限并排除 Git。凭据不是普通数据库备份的一部分，处理凭据迁移时单独设计安全回退，不复制明文到仓库。
3. 用隔离数据和合成内容验证主要行为、迁移、取消与并发；在仓库运行 `npm run verify`（类型检查、测试、构建）。涉及发布时检查 `npm pack --dry-run` 和 Git 差异，不泄露私密内容。
4. 按实际需要在隔离测试伙伴上验证宿主接入和 UI，勿向正式聊天发送测试消息。模型生成自然度、跨日成长、真实宿主行为和费用以相应实测为准，不以单元测试充当实机验收。
5. 记录已验证和未验证内容，更新本文、专项文档及恢复说明；确认任务和草稿状态后再安排 DSH 重启，避免中断工作。
