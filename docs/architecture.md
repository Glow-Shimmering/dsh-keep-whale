# 架构与边界

插件拥有自己的伙伴、聊天、互动、记忆、任务和计费状态。DSH 提供侧栏／浮层扩展点、模型接口和普通会话事件；伙伴聊天不创建 DSH 普通会话，也不向普通会话注入伙伴人格。

```text
普通 DSH 新对话 ──> 来源与排除规则 ──> 后台整理 ──> 有依据的记忆
                                                    │
浮层／独立聊天面板 ──> 伙伴服务 ──> DSH 模型接口 <─┘
                           │
                    独立消息与互动存储
```

## 数据与观察

数据位于 `$DSH_HOME/dsh-keep-whale/`，使用独立 SQLite 数据库及媒体目录。消息、记忆、来源、互动、任务和费用分别保存；角色初始设定与真实来源分开。普通 DSH 对话只观察启用后产生的用户消息及其助手上下文，排除选定会话、工作区和子代理；不会把 DeepSeek 的回答当作用户事实或伙伴自己的经历。删除记忆会撤回关联依据和相关派生项，聊天消息保留；删除聊天时撤回对应来源。

首次初始化可读取安装器生成的一次性 `bootstrap.json`。它只包含名称、显式设置及为隔离旧伙伴而保存的会话排除 ID，不迁入旧消息或旧记忆。旧数据库及原数据在独立位置保留，回退不会用旧备份覆盖新插件数据。用户导入的图片和皮肤保存在本机；仓库仅包含默认蓝色鲸鱼娘生成素材。

## 调度与费用

后台整理、主动联系由宿主插件服务调度，不把前端心跳作为后台任务是否存活的唯一依据。前端向宿主报告输入状态，主动投递要求窗口状态可确认、没有输入至少约 3 秒；普通 DSH 任务运行不单独阻止投递。安静陪伴只限制主动联系，不关闭记忆整理。休眠、关闭或异常中断后的任务记录会保留状态，不虚构完成。

模型请求复用 DSH 已配置的 provider 与 `llm.stream`，伙伴聊天和后台整理分别记录费用。后台调用按所选线路单价预留并按返回用量结算；默认每日上限 100 积分，可调整。用量不明或实际费用超过预留时，当日停止后续后台调用并在近况标记；北京时间次日按新的日账本重新判断。手动聊天单独核算，不消耗该后台预算。模型服务商的实际账单和共享账户余额仍以提供商为准。

安装器保存配置前后哈希、源码位置与备份路径；恢复前检查 profile 文件与插件链接，遇到后续修改时拒绝覆盖。当前已有自动化检查与 DSH 桌面端隔离伙伴验收；覆盖独立主面板、真实流式模型调用、图片、互动与记忆整理。多窗口及异常费用等分支使用隔离测试验证；跨日人格成长与长期运行仍需持续观察。

## 记忆网络 v2

`Store` 保留原有消息和来源，新增 FTS5 中文检索、版本化向量、关系、来源片段撤回及历史。`Service` 在聊天前调用混合检索，再构造伙伴独有的上下文；不会向宿主普通会话注入人格。`Embeddings` 负责独立兼容接口、私密配置、连接检查与增量索引。

关系中的相关/同场合用于最多两跳检索；证据依赖用于删除传播，二者不混用。软遗忘不删除文本，检索不会增加证据数量。`revision` 保护在途模型结果；独立的删除预览版本防止影响清单过期。原聊天展示保留，发送模型的历史会遮蔽已撤回原文片段。

管理接口新增 `memory.list/detail/profile/preview/correct` 和 `embedding.configure/check`，继续使用原 `/keep-whale/action` 鉴权入口。`memory.delete` 支持预览版本与 `all`；事实更正入口不能直接改写人格。新 snapshot 只保留少量记忆概览，详情与完整分页由管理接口读取，不将密钥放入 snapshot。

后台整理按来源去重，任务查询覆盖全库，不因近况列表仅显示近期任务而重新消费旧失败批次。截断缩小批次且保留余项；索引失败需手动重试。向量用量与生成用量保留供应商原始单位和折算金额，统一预留后台额度，手动调用单列。详见[记忆说明](memory.md)。
