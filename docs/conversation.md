# 聊天节奏与自然接话

表达由话题决定，允许几句短话，也允许一段稍长的话。停止的依据是这一轮的意思已说清楚、适合把话交给对方，而不是固定字数、句数或问句。用户明确需要深入讨论时可以展开；日常聊天避免一次穷尽所有角度、把后续交流也替双方说完。

生成上下文会提醒伙伴理解当下是分享、吐槽、讨论、求助还是告别，接住具体细节，并自然贡献看法、理由或联想。它不是“回应情绪—建议—反问”的固定流程，也不要求每轮包含全部元素。仍以实际记录为依据，不假装看过比赛、视频或经历了未记录的事。

普通回复继续以一条流式消息呈现，不通过拆成多条、延迟发送或额外模型调用模拟聊天感。模型的 token 上限仍是运行保护，不作为目标回复长度；不按字符截断已经完整生成的正文。

## 主动接话

- 可以针对当前话题补充一个尚未说过的具体看法，不要求有新的外部事件；不能只发“又想到一点”、重复关心或追问来要求回应。
- 判断时使用带时间、来源和角色的最近完整交流；失败、取消和流式半条不进入判断，已撤回来源仍遵守原有遮蔽规则。
- 专属聊天只考虑最近一轮的来源，避免逐条补回旧话题。新的普通对话观察仍可作为联系线索，其内容不能冒充与伙伴的共同经历。
- 同一段对话主动补充过一次后，等待用户回来并完成正常交流，不继续拿旧来源连发。此后在允许观察的普通对话中出现的新线索仍可供判断，既不永久沉默，也不把新线索当成必须发送的任务。尚未完成或失败的普通回复不会由主动联系代答。
- 已实际告别、说要去忙或表达暂时不聊时应等待；由模型结合上下文判断，不把包含“晚安”的引用或讨论硬判为告别。
- 继续遵守输入状态可确认、停止输入至少三秒、免打扰与现有计费规则。发送前再次核对消息位置、输入状态和设置；用户已继续聊天或状态变化时放弃旧草稿，不补发。

这些调整不修改人格成长门槛，不将说话规则写成真实记忆，不改变普通 DeepSeek 会话，也不增加模型调用阶段。

## 验证边界

自动化使用临时数据库和合成内容，覆盖长短正文完整保存、单轮流式消息、旧话题过滤、未完成消息排除、撤回遮蔽、多来源等待、重启、输入中、安静与在途消息变化。模拟模型只能证明路由和发送规则，不能证明实际模型已经更自然。

多轮人工评估应在隔离测试伙伴中进行，至少包括：

| 场景 | 观察内容 |
|---|---|
| 分享进展，接着补充一个细节 | 是否沿原话题展开具体回应，避免通用祝福收尾 |
| 观点讨论，表达不同意见 | 能否解释自己的判断，而非只附和或连续反问 |
| 简单招呼、玩笑与明确求助 | 长短是否随内容变化，求助时能认真展开 |
| 说晚安或先去忙，与讨论“晚安”这个词 | 能否根据实际语境区分告别和普通讨论 |
| 说完暂未回复 | 有具体补充才接话，主动说过后不会连发催促 |
| 换话题、图片聊天与长停顿后回来 | 不追补已过去的话题、不编造画面和停顿期间经历 |

评估内容贡献、承接、交棒位置、重复与事实依据，不用平均字数或问号数量作为成功指标。真实聊天记录不作为测试夹具提交，也不在正式伙伴聊天中发送管理或测试指令。
