# 关联记忆与语义回想

## 相处中会发生什么

伙伴聊天先根据当前话题检索相关记忆，再结合初始人格、近期真实互动与当前状态回应。很久以前的相关经历可以被找回，近期但无关的记录不会固定占据提示词。无来源的推测、被撤回内容和未完成的伙伴回复不能成为学习证据；用户已经发送的真实陈述仍会保留为来源。

用户事实、共同经历、普通对话观察、暂定理解和后天倾向分开保存。初始人格是角色设定，始终与真实经历分开。已完成回复的原文可以用于核对实际表达行为，但其中“我已经改变”等自述不能证明人格成长。稳定倾向要求至少三个独立场合、两个北京时间日期的具体支持证据；有反例时保留待确认状态，数量门槛不代表内容必然正确。

本地全文索引支持中文；配置语义服务后，融合关键词、向量相似度与最多两跳关联。相似或同话题关系只提供检索线索，不成为新的证据。相同真实场合可以建立有出处的事件关联。默认按 30 天半衰期衰减召回权重中的时间项，并保留检索下限；原文不自动删除，明确边界不衰减。系统自己查阅记忆不会强化证据。

## 记忆管理

在“记忆”页按类型、时间和状态筛选，打开详情可以查看原文、支持和相反证据、关联记忆及变化历史。语义搜索需要明确点击；输入和普通刷新不自动调用向量服务。“人格档案”展示初始倾向、暂定理解和逐渐形成的倾向，没有人格滑块。

用户事实可直接更正，更正作为新的管理来源，不发到聊天。暂定理解和人格倾向只能提出纠正或撤回。删除预览展示直接和派生影响；单纯相关的独立记忆不随之删除。删除清理依赖、历史副本和向量，旧任务不能重新写回；用户之后明确重新提供的信息可形成新来源。

原始聊天消息仍在聊天页保留。后续模型上下文会遮蔽已撤回的来源片段，防止从同一原文重新学习；这不承诺擦除所有其他独立表达过相同含义的消息。若要删除消息本身，请使用聊天管理。已有旧记忆缺少片段坐标时保守撤回整个来源，预览会展示受影响记录。

## 远程向量服务

在“设置 → 语义回想与索引”填写：

| 字段 | 说明 |
| --- | --- |
| 服务地址 | 兼容 `/embeddings` 的 HTTPS 基础地址或完整端点；本机开发可用 localhost HTTP |
| 模型与维度 | 使用供应商支持的模型及维度；例如 text-embedding-v4 / 1024 |
| 密钥 | 通过宿主 credentials 服务保存，不回传页面、导出或日志；当前 DSH 提供器仍是权限受限的明文存储 |
| 输入单价 | 每百万输入 token 的供应商价格，须按实际线路填写 |
| 费用单位与换算 | 供应商原单位、每元对应多少原单位，用于折算当前预算单位 |

百炼示例：从控制台取得当前业务空间的 OpenAI 兼容基础地址，模型填写 `text-embedding-v4`，维度 `1024`；北京地域当前原价为每百万 token 0.5 元，单位选“元”，每元原单位为 1。地址与价格以[官方兼容接口](https://docs.bailian.console.aliyun.com/zh/model-studio/embedding-interfaces-compatible-with-openai)和[模型价格](https://help.aliyun.com/zh/model-studio/text-embedding-v4)为准，示例不会自动配置或启用。

保存后点击检查连接。检查只发送合成短句并单独计费；通过后自动逐步索引有效记忆。关闭服务、修改模型/维度/密钥或单价后需重新检查。更换服务域名时需提供该接口自己的密钥，防止旧凭据发往另一个供应商。同域路径调整可沿用密钥，但需要重新检查；等价的火山方舟地址共用同一凭据引用。旧接口引用保留在 DSH 中，清除按钮只清除当前接口的引用。向量按线路、内容版本缓存，不重新嵌入每轮全部历史。

火山方舟 `doubao-embedding-vision-*` 使用多模态向量接口，即使这里只索引文字，也不能使用标准文本 `/embeddings` 协议。插件会自动选择多模态请求和响应格式。北京地域地址可填 `https://ark.cn-beijing.volces.com/api/v3` 或完整 `/api/v3/embeddings/multimodal` 端点；仅填写北京服务域名时也会补齐这个路径。使用 `ep-*` 推理接入点 ID 时，请填写完整多模态端点以选择正确协议。`doubao-embedding-vision-251215` 支持 1024 或 2048 维，密钥、模型开通状态与单价请以自己的账户为准。接口依据：[火山官方多模态向量化 API](https://console.volcengine.com/ark/region:cn-beijing/docs/multimodal-vectorization-api)。

多模态接口会融合同一请求内的内容，因此不同记忆逐条请求，不混成一个向量。每个索引任务先预留整批费用，最后汇总已核实用量结算一次；途中失败且用量不完整时记为费用未核实，停止后续请求，整批向量不写入。手动重试该批可能再次产生费用。连接失败会显示安全的 HTTP 状态或向量维度提示，不展示供应商原始错误文本和密钥。

未配置、断网、超时或接口失败时使用本地检索，聊天仍可用。失败索引需要在近况手动重试，不持续消耗额度重试同一批；后续其他记忆可以继续索引。中断或内容变化导致未保存时会明确记录，重启不会自动重复原批次。普通观察关闭或排除范围调整后，不再把相关旧来源用于新的整理或远程索引；已经保存的记忆仍可在管理页查看和删除。

## 费用与后台

聊天、自动索引、记忆整理、人格整理和主动联系不设每日预算上限。手动聊天、该次对话回想、管理语义搜索和连接检查仍单独展示费用；近况保留供应商原始金额和折算金额。折算不代表向量服务扣除了 tju 账户积分，也不代表插件知道全账号余额。

现有调用开始前记录费用预估，结束后按实际用量结算，仅用于记录而非额度准入。失败也可能收费；缺失用量或 DSH 中断时保留“费用未核实”，不清零、不改写为实际扣费，也不阻止后续正常聊天、整理、索引或主动联系。历史已知超出预估的账目同样原样保留。后台仍需可靠单价及有效配置。当前失败尝试用量未知时不自动重试；有可靠用量的截断/格式错误最多缩小批次重试一次，失败任务不会每轮自动重跑。旧中断任务可由用户在近况手动重试。

设置中的默认 100 积分日预算约束“逛 B 站”的选片、视频理解及看法生成；调用入口显式标记 B 站用途：`Store.reserve(..., details, 'bilibili')`。账本通过独立用途元数据隔离计费，未标记的旧账目不会自动算作 B 站费用；预算准入、预留、已核实支出、用户确认的暂记金额及未知费用保护作用于此用途。此限额不是供应商账户硬限额，普通聊天和记忆整理不受该上限拦截。

出现 B 站用途的未知费用时，近况会展示“B 站费用确认与恢复”。用户可逐笔明确接受按预留暂记本地预算；原账目和未知状态仍保留，实际收费可能更高，暂记不能保证供应商实扣总额不超上限。确认只适用于当前北京时间日期及单位，且不会发起模型调用。聊天和记忆整理无需进行这类确认。[B 站费用和记录边界](bilibili.md)。

安静陪伴抑制主动消息，不停止整理；输入状态未知或尚未停止输入三秒时，不投递主动内容。后台总开关、配置校验、串行控制、超时、中断和内容撤回保护均不受预算范围调整影响。

## 数据、升级与限制

SQLite schema v2 添加来源片段、全文索引、关系、向量、历史与撤回记录。迁移前在原数据目录生成一致性备份，保留身份、聊天、互动和旧记忆。不会回读启用前的普通 DSH 对话，也不会从旧插件导入人格或记忆。

升级及回退参见[安装与恢复](install.md#记忆网络升级与回退)。原始数据和密钥均不进入公开仓库或 npm 安装包。

检索与来源检查能减少错误，不能证明模型每次推断正确。人格自然度、复杂矛盾理解及长期稳定性需要跨日真实相处评估；远程向量效果取决于所选模型。记忆网络目前只索引文字，不训练模型或新增图数据库；B 站个人浏览经历以独立记录参与相关聊天，不直接改写稳定人格。

设计参考：[A-MEM](https://arxiv.org/abs/2502.12110)、[MemoryBank](https://arxiv.org/abs/2305.10250)。本插件实现自己的数据与检索流程，没有引入这些项目的整套服务。
