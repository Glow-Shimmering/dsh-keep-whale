# dsh-keep-whale

一个运行在 DeepSeek Harness（DSH）中的独立陪伴伙伴插件。默认名为「大肥鱼」，采用蓝色鲸鱼娘形象。你可以给伙伴起自己的名字、聊天、摸摸和喂食；她有自己的初始性格，也会结合真实相处中形成的记忆回应你。

伙伴有独立聊天空间，普通 DSH 会话继续由 DeepSeek 回答。首版不包含 B 站浏览、语音或 DSH 退出后的后台运行。

## 能做什么

- **独立聊天与轻互动**：通过侧栏或浮层进入伙伴聊天；采用 DSH 风格的消息布局与固定输入区，支持 Markdown 回复、复制、失败重试和图片缩略图。向上翻阅时不强制跳回底部，面板内切换页签保留未发送草稿。图片需要所选模型及宿主支持。摸摸有轻抚动画，喂食有点心与点头动画；短反馈结合当前心情与近期互动避开重复。互动记录实际动作，不调用模型、不强制改变心情；支持系统的减少动态效果设置。
- **关联记忆与回想**：按当前话题融合中文关键词、可选远程向量和最多两层关联，找回相关旧事。区分用户事实、共同经历、普通对话观察、暂定理解和后天倾向；记录来源、反例与时间变化，软遗忘只降低召回优先级。
- **记忆与人格管理**：分页筛选、原文依据、关联和历史、人格档案、事实更正及删除影响预览。人格倾向不能直接编辑；删除会撤回派生内容和向量，旧任务不能恢复它。管理操作不发到聊天。[配置和边界](docs/memory.md)。
- **观察普通对话**：可以选择让伙伴了解启用后新的 DSH 对话，并排除指定会话或工作区；不回读启用前的历史，也不接管普通对话。观察默认关闭，需要你主动开启。
- **主动联系与安静陪伴**：伙伴可以在有内容想说时发到独立聊天；等待停止输入约 3 秒且窗口状态可确认后发送。安静陪伴关闭主动消息和提示，记忆整理仍可运行。
- **近况与设置**：查看后台任务、费用、互动和失败原因；选择模型、自行填写单价和预算，导入本地皮肤。

角色默认倾向温和、有自己的判断；它是回应的起点，不是每种情境的固定台词。多轮相处的自然度和记忆质量仍需实际体验与评估，不能由一次回复证明。

## 模型、费用与隐私

在「设置 → 模型与预算」选择 DSH 已配置的模型，按所选**提供商线路**填写每百万 token 的输入、缓存命中和输出单价及费用单位。后台记忆整理、语义索引和主动联系共用每日预算，默认 **100 积分**，可调整；手动聊天、对话回想、管理语义搜索和连接检查另行核算，不占用该后台上限。未配置可靠单价、无法核实当日后台费用或当日预算不足时，后台调用会暂停；费用未核实造成的暂停按北京时间自然日重置，不代表历史账单已核实。手动聊天费用若无法核实，界面会标记。

远程语义服务默认未配置，需独立保存接口、密钥和单价并手动检查；无法使用时回退本地检索。向量供应商单独收费，折算预算不代表扣除 tju 积分。

聊天、记忆和设置保存在本机 `$DSH_HOME/dsh-keep-whale/`。模型调用会将生成回复或整理记忆所需的内容发送给你选择的模型服务商；开启观察后，新普通对话的相关内容也可能用于后台整理。请根据需要关闭观察或排除范围。私有数据、模型凭据和本地导入的皮肤不提交到仓库。

## 从源码安装

当前以源码构建和本地链接方式安装，**尚未发布 npm 包**。需要 Node.js 22.21 或更新版本，以及可用的 DSH 桌面 profile。先取得源码，在项目目录执行：

```sh
npm ci
npm run verify
mkdir -p "$HOME/dsh-backups"
```

完整退出 DSH 后，按 [安装与恢复说明](docs/install.md) 使用安装脚本。脚本先备份旧配置和旧记忆数据库，再切换已知旧插件；首次使用新插件从空白记忆开始。完成后重新打开 DSH，在设置中选择模型、填写该线路单价，并根据需要开启观察。

恢复旧配置前同样需要完整退出 DSH；脚本会核对文件是否被后续修改，不覆盖有冲突的配置。[查看恢复步骤](docs/install.md#恢复旧版)。

## 开发与授权

`npm run verify` 依次执行类型检查、自动化测试和构建。测试覆盖迁移、来源片段、中文与向量召回、时间变化、两跳关联、删除传播、并发预算和降级。0.1 版已进行隔离伙伴真实文字／图片验收；记忆网络新增测试与实机结果单独列在验证文档。跨日人格成长与真实远程向量效果不能由静态或模拟测试证明。[设计](docs/design.md) · [架构](docs/architecture.md)
