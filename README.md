# dsh-keep-whale

一个运行在 DeepSeek Harness（DSH）中的独立陪伴伙伴插件。默认名为「大肥鱼」，采用蓝色鲸鱼娘形象。你可以给伙伴起自己的名字、聊天、摸摸和喂食；她有自己的初始性格，也会结合真实相处中形成的记忆回应你。

伙伴有独立聊天空间，普通 DSH 会话继续由 DeepSeek 回答。插件支持使用独立小号浏览 B 站；语音和 DSH 退出后的后台运行暂未提供。

## 能做什么

- **独立聊天与轻互动**：通过侧栏或浮层进入伙伴聊天；采用 DSH 风格的消息布局与固定输入区，支持 Markdown 回复、复制、失败重试和图片缩略图。向上翻阅时不强制跳回底部，面板内切换页签保留未发送草稿。图片需要所选模型及宿主支持。当前皮肤可绑定本地八种心情表情及摸摸、喂食 GIF，短动作播放后恢复当前心情；收起后保留可拖动的 56×56 方形头像、未读和离线角标。未关联素材包时保留当前皮肤与轻量互动反馈；短反馈结合当前心情与近期互动避开重复。互动记录实际动作，不调用模型、不强制改变心情；支持系统的减少动态效果设置。
- **关联记忆与回想**：按当前话题融合中文关键词、可选远程向量和最多两层关联，找回相关旧事。区分用户事实、共同经历、普通对话观察、暂定理解和后天倾向；记录来源、反例与时间变化，软遗忘只降低召回优先级。
- **记忆与人格管理**：分页筛选、原文依据、关联和历史、人格档案、事实更正及删除影响预览。人格倾向不能直接编辑；删除会撤回派生内容和向量，旧任务不能恢复它。管理操作不发到聊天。[配置和边界](docs/memory.md)。
- **观察普通对话**：可以选择让伙伴了解启用后新的 DSH 对话，并排除指定会话或工作区；不回读启用前的历史，也不接管普通对话。观察默认关闭，需要你主动开启。
- **主动联系与安静陪伴**：伙伴可以在有内容想说时发到独立聊天；等待停止输入约 3 秒且窗口状态可确认后发送。安静陪伴关闭主动消息和提示，记忆整理仍可运行。
- **逛 B 站**：手动登录并确认伙伴的独立小号后，可自主选片、接收推荐、读取可用字幕和抽样画面、保存个人看法；在有想法时主动分享，也可以按设置点赞或收藏。尝试和成功分别计数，失败原因与理解范围可查，支持搜索、删除和屏蔽。[使用说明与限制](docs/bilibili.md)。
- **近况与设置**：查看后台任务、费用、互动和失败原因；选择模型、自行填写单价和预算，导入本地皮肤。

角色默认倾向温和、有自己的判断；它是回应的起点，不是每种情境的固定台词。多轮相处的自然度和记忆质量仍需实际体验与评估，不能由一次回复证明。

聊天按完整意思与自然交棒点收尾，长短随内容变化，不固定句数或每轮反问。主动接话只补充值得说的新内容，同一段对话不逐个追补旧话题；以后有新的真实交流线索仍可考虑分享。[聊天规则与验证边界](docs/conversation.md)。形象素材采用本地皮肤绑定，制作与回退见[形象与动画](docs/appearance.md)。

## 模型、费用与隐私

在「设置 → 模型与预算」选择 DSH 已配置的模型，按所选**提供商线路**填写每百万 token 的输入、缓存命中和输出单价及费用单位。聊天、记忆整理、语义索引、主动联系和手动语义调用均只记录费用，不设每日预算上限；历史未知费用不会阻止这些功能。缺失用量仍标为未核实，不冒充零费用或已核实费用。后台调用仍需配置可靠单价，失败、超时、并发及有限重试保护继续保留。

默认 **100 积分** 的可调预算用于 B 站选片、视频理解和分享准备；其他现有功能不受该上限约束。费用无法核实会暂停后续 B 站模型任务；预留及确认暂记不能保证供应商实扣不超过预算，它不是供应商账户硬限额，也不是余额。

远程语义服务默认未配置，需设置接口、密钥和单价并手动检查；无法使用时回退本地检索。密钥通过 DSH `credentials` 服务保存，插件不再单独写入明文密钥文件；旧文件在宿主保存、读回核实后自动删除。DSH 当前本地凭据仍是权限受限的明文文件，不是系统钥匙串加密。向量供应商单独收费，折算预算不代表扣除 tju 积分。

聊天、记忆、B 站浏览记录和设置保存在本机 `$DSH_HOME/dsh-keep-whale/`。模型调用会将生成回复、整理记忆或理解视频所需内容发送给你选择的模型服务商；开启观察后，新普通对话的相关内容也可能用于后台整理。请根据需要关闭观察或排除范围。B 站登录状态由伙伴独立 Chrome profile 管理，不自动复制旧插件账号；该 profile、私有数据、模型凭据和本地导入的皮肤不提交到仓库或安装包。

## 从源码安装

当前以源码构建和本地链接方式安装，**尚未发布 npm 包**。需要 Node.js 22.21 或更新版本，以及可用的 DSH 桌面 profile。先取得源码，在项目目录执行：

```sh
npm ci
npm run verify
mkdir -p "$HOME/dsh-backups"
```

完整退出 DSH 后，按 [安装与恢复说明](docs/install.md) 使用安装脚本。脚本先备份旧配置和旧记忆数据库，再切换已知旧插件；首次使用新插件从空白记忆开始。完成后重新打开 DSH，在设置中选择模型、填写该线路单价，并根据需要开启观察。

恢复旧配置前同样需要完整退出 DSH；脚本会核对文件是否被后续修改，不覆盖有冲突的配置。[查看恢复步骤](docs/install.md#恢复旧版)。

## 开发与授权

`npm run verify` 依次执行类型检查、自动化测试和构建。测试覆盖迁移、来源片段、中文与向量召回、时间变化、两跳关联、删除传播、并发预算和降级。0.1 版已进行隔离伙伴真实文字／图片验收；记忆网络新增测试与实机结果单独列在验证文档。B 站真实小号、视频、模型调用与持续浏览的端到端体验仍需在目标环境验证，能力声明和模拟测试不能代表真实视频成功。[开发参考](docs/development.md) · [设计](docs/design.md) · [架构](docs/architecture.md)

后续每次升级都要检查并适当更新开发参考和受影响的专项文档；具体维护要求见 [AGENTS.md](AGENTS.md)。
